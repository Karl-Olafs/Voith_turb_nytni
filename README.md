# Voith_turb_nytni
Forrit sem les gögn úr Voith og reiknar/plottar nýtni
Virknin er eftirfarandi.
1. Plottar fyrst eftirfarandi úr VOITH:
    -Gate opening
    -Runner blade position
    -2CFA.Head
    -Water flow
    -Active power
3. Exportar þetta sem time-series úr VOITH
4. Færð csv með nafninu "combined-data.csv"
5. Færir það inní sömu möppu og forritið
6. Keyrir forritið
7. Færð ýmis plot undir möppu sem ber heitið "frozen_flow_efficiency_gate_output"
